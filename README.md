## Hey, I'm Samuel 👋

Full-Stack Developer based in Berlin. I recently graduated from 42 Berlin,
where I spent the last couple of years building things instead of sitting in lectures.

My background is a mix of software development, technical support, and event
technology — which mostly means I've had to make things work under pressure
and explain them to non-technical people.

---

### What I'm building

**Local AI Control Plane** — a self-hosted orchestration platform for deploying,
scheduling, and managing AI agents and local LLM workloads across distributed
compute nodes. Think lightweight Kubernetes, but designed around AI agents and
heterogeneous hardware (GPU nodes, CPU-only machines, mixed setups).

The idea is to give teams control over their AI infrastructure without depending
on cloud providers. The first milestone is a standalone GitHub PR Review Agent;
the orchestration layer gets built around a real workload rather than in the abstract.
Early stages, but the foundation and tooling are in place.

Also starting a side project for a club. A friend is standing up
a Linux server and I'm exploring an AI-assisted management layer on top: bookings,
inventory, staff scheduling, probably a mobile app. Figuring out the architecture
as I go.

---

### What I picked up from recent production work

- Offline-first architecture — local SQLite, background sync, conflict resolution
- Streaming AI output and background job queues
- Monorepo structure with shared packages across web and mobile
- End-to-end and integration testing (Playwright, Vitest)
- Multi-tab state management and reactive local data
